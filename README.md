## Running the Project
Make sure you have Docker installed on your system, then run the executable script for Metabase data (.sh for Linux/MacOS and .bat for Windows) -- make sure the file is executable (chmod +x restore-metabase-data.sh). After you run the script run this command: docker-compose up --build

## Development
Please create a new branch when developing a new feature. Branch name can be your own name or feature name.
